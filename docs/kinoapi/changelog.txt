
Лог изменений¶
2.11.2020¶
Добавлено голосование за контент
22.09.2020¶
История просмотров, бета
15.09.2020¶
Добавились два метода для получения ссылок для видео и субтитры для media
и ссылка на файл для media.
Добавился параметр nolinks в item - убирает ссылки на контент из ответа.
Убран параметр exclude_info в item.
22.01.2019¶
В Справочники добавлен Список качеств видео.
В Видео контент добавлен фильтр по качеству видео.
15.12.2018¶
В Список медиа-контента добавлены аудио-дорожки
Добавлен новый эндпоинт Справочники.
Локации серверов
Типы стриминга
Типы озвучек
Авторы озвучек
Добавлены Настройки устройства.  Теперь каждое
устройство будет обладать настройками, которые будут храниться у нас,
на их основании будут формироваться плейлисты и тд.
Поддержка SSL
Поддержка HEVC
Поддержка HDR
Поддержка 4K
Выбор сервера, откуда получать контент
Выбор типа стриминга
В ответ удаления устройства добавлено поле current. Удаление устройства
14.02.2017¶
Добавлено поле ac3 в item
17.10.2016¶
Добавлены ярлыки для горячих, свежих, популярныех фильмов
14.08.2016¶
Добавлен новый параметр фильрации в /items/index - force. Для пропуска проверок на сомнительный контент
и контент эротического характера.
27.05.2016¶
Добавлены новые методы для работы с закладками. Создание/добавление/удаление.
В ответ /items/index pagination добавлено поле total_count - общее количество найденых фильмов.
27.05.2016¶
Добавлено поле subscribed в item - подписан ли пользователь на сериал (алиас in_watchlist)
25.05.2016¶
Добавлено поле advert в item - обозначает присутствие рекламных вставок в видео
17.05.2016¶
Введено ограничение активных устройств на аккаунт, после активации устройства
желательно присылать информацию об этом устройстве.
* Введение. Управление устройствами.
18.03.2016¶
Видео контент. Добавилось поле /items/finished - Статус сериала окончен или нет.
Видео контент. Добавился параметр finished в фильтр /items/
Видео контент. Изменился вид trailer в /items/, убраны ссылки на превью и блок с файлами.
Трейлер к контенту. Добавилось новоее действие в /items/ trailer - /v1/items/trailer?[id=123|sid=l_c74hFbnK]
Видео контент. Добавился фильтр по актерам и режисерам - /items?actor=Actor1,Actor2+Actor3
16.03.2016¶
Изменилось поле /items/watched - Добавилось пограничное состояние -1,0,1 (не смотрели/начали смотреть/посмотрели)
Добавилось поле /items/watching - Расширенная версия watched со статусом и временем просмотра
15.03.2016¶
Изменилось поле /items/trailer
В /items/ добавились поля:
subtitles - Субтитры эпизода/видео
