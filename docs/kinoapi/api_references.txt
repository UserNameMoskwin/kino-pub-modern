Список локаций сервера¶
Запрос:
GET https://api.service-kp.com/v1/references/server-location
HTTP/1.1 200 OK
Content-Type: application/json
{
  'status': 200,
  'items': [
     {
        'id': 1,
        'location': 'de',
        'name': 'Германия',
     }
  ],
}
