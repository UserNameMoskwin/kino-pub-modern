Введение¶
Все ошибки возвращаются в JSON формате с HTTP статусом 4xx или 5xx.
Пример:
HTTP/1.1 401 OK
Content-Type: application/json
Cache-Control: no-store
{
    "name":"Unauthorized",
    "message":"You are requesting with an invalid credential.",
    "code":0,
    "status":401
}
