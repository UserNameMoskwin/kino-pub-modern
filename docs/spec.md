# Что должно делать приложение

Личный клиент kino.pub для Android TV. Телевизор: Xiaomi 65" (P1 или Q1E), 4K,
около 2 ГБ памяти, слабый процессор, свой лаунчер. Стек: Kotlin, Compose for TV, Media3.

## Принятые решения

- Пишем с нуля, чужие клиенты не форкаем.
- Ключ приложения — публичный от Kodi-плагина (`client_id=xbmc`). Если отзовут,
  запасной вариант — официальное приложение.
- Список адресов API с автопереключением (сделано в `core/`).
- HDR / Dolby Vision и строку «Продолжить» на главном экране Google TV не делаем.
- Все записи идут в настоящий аккаунт, песочницы нет.
- Рейтинг Кинопоиска не показываем нигде. Только IMDb.

## Главный экран, сверху вниз

1. Продолжить просмотр — без детского.
2. Нелли: продолжить.
3. Нелли: избранное.
4. Новинки: фильмы — по рейтингу IMDb, без мультфильмов.
5. Новинки: сериалы — по рейтингу IMDb, без мультфильмов.
6. Рекомендации — отложено, см. ниже.

«Продолжить» — одна карточка на фильм или сериал, а не на серию: обложка, название,
сезон и серия, полоска прогресса.

## Детское (Нелли)

- Детское = жанр «Мультфильм» + всё из папки закладок «Нелли».
- Детское исключается из общего «Продолжить» и из новинок.
- На карточке есть кнопки «Для Нелли» (добавить в папку) и «Не детское»
  (исключение для взрослых мультсериалов, хранится в приложении).
- Аниме считается взрослым контентом.

## Звук и субтитры по умолчанию

| | Озвучка | Субтитры |
|---|---|---|
| Нелли | русский дубляж | выключены |
| Всё остальное | оригинальная дорожка | первые русские в списке, не forced |

- Оригинал не английский — всё равно оригинал + русские субтитры.
- Русских субтитров нет — русская озвучка.
- Правило применяется при каждом запуске видео и хранится в приложении.
- Ручной выбор на конкретном сериале запоминается для этого сериала.

## Плеер и выбор дорожек

- Выбор озвучки, субтитров, качества, скорости, сервера: нажал на пункт — применилось,
  панель закрылась. Без чекбоксов и кнопки «ОК».
- При открытии панели фокус стоит на текущем выборе.
- Качество по умолчанию — 4K, если оно есть.

## Сервер

- Текущий сервер (Россия, Нидерланды и другие) виден на главном экране и в плеере.
- Переключение в два нажатия, без захода в настройки.
- Список берётся из `v1/references/server-location`, выбор пишется в настройки устройства.

## Скорость и дизайн

- Обложки кэшируются на диск, грузятся в размере под карточку.
- Главный экран рисуется из сохранённых данных, обновляется в фоне.
- В памяти только видимые ряды.
- Тёмный интерфейс в духе Netflix / Apple TV, крупные обложки.
- Анимации: только подсветка выбранной карточки и плавная прокрутка.

## Проверено на живом сервере (2026-11-15)

- Вход по коду через `https://kino.watch/api/oauth2/device` работает целиком, включая обмен
  кода на токен, с телевизора. Обновление токена вживую ещё не срабатывало (токен живёт сутки).
- Сортировка `sort=imdb_rating-` на сервере есть, но фильтр `conditions` по `imdb_votes` не
  применяется, а без него наверх выходят фильмы с десятком голосов. Поэтому новинки —
  это 150 последних из `items/fresh` (3 страницы, сервер отдаёт максимум 50), в приложении
  отсеиваются мультфильмы и всё с `imdb_votes` < 1000, остальное сортируется по рейтингу.
- У субтитров есть поле `forced` (в документации его нет); вместо `url` приходит `file`.
- У обложек есть размер `wide` (горизонтальный) — он идёт в ряды «Продолжить». Некоторые
  весят 2–3 МБ и в первый раз грузятся несколько секунд.
- «Продолжить» строится из `history` (4 страницы по 50 строк, по одной строке на серию):
  `watching/serials` отдаёт не больше 50 сериалов и без порядка, свежих в нём может не быть.
  Если последняя серия досмотрена, следующая ищется через `watching?id=`.
- `pagination.total` — число страниц, число записей — `total_items`. `history` отдаёт
  список в поле `history`, а не `items`.
- Папки «Нелли» в закладках нет; детская папка сейчас называется «мутики». Приложение
  принимает оба названия (`KIDS_FOLDER_TITLES`).
- `kino.watch/api` не обслуживает `device/<id>/settings` (404); смена сервера уходит на
  запасные адреса `api.srvkp.com` / `api.service-kp.com` — они работают с тем же токеном.
- Серверов два: Нидерланды (id 1) и Россия (id 3).
- `items/<id>`, `items/search`, `bookmarks/get-item-folders`, `bookmarks/add` и
  `bookmarks/remove-item` совпадают с документацией. `nolinks=1` ссылки всё равно
  оставляет (поле `files`), карточка сериала на 10 серий весит около 28 КБ.

Не проверено: обновление токена, время холодного запуска, поведение при 2 ГБ памяти под нагрузкой.

## Отложено

- Блок рекомендаций: источник оценок — приложение Must или IMDb. Отдельное исследование
  после главной и плеера.

## Шаги

1. Каркас и вход — готово, вход проверен на телевизоре.
2. Главный экран — пять рядов и переключатель сервера работают на телевизоре.
3. Карточка, сезоны, поиск — работает на телевизоре: карточка с описанием, сезонами и
   сериями, кнопки «Для Нелли» (папка создаётся как «Нелли», если детской нет) и «Не детское»
   (только у мультфильмов, хранится в приложении), поиск с экранной клавиатурой, «Назад»
   с возвратом фокуса и прокрутки. «Продолжить» в карточке выбирает ту же серию, что и
   главный экран (по отметкам `watching?id=`). Кнопка «Смотреть» и серии пока ничего не
   запускают. Не проверено: создание папки «Нелли» (детская папка уже есть) и поиск
   кириллицей с пульта (через adb вводится только латиница).
   Вне плана добавлен раздел «Настройки» по образцу официального приложения (версия 1.34,
   пункты сняты с телевизора 2026-11-15) — см. ниже.
4. Плеер.
5. Проверка на телевизоре и доводка.

## Настройки

Кнопка «Настройки» в шапке главного экрана. Состав повторяет официальное приложение.

- **Устройство** (хранится на стороне сервиса, меняется сразу): название, сервер, тест
  скорости, переключатели SSL / HEVC / HDR / 4K / смешанный плейлист, отвязка устройства
  (с подтверждением, после неё нужен новый вход по коду).
- **Интерфейс**: «Отключение аниме» — убирает аниме из новинок.
- **Плеер**: выбор плеера, качество, тип потока (на стороне сервиса), небольшой буфер,
  автофреймрейт, автовыбор ac3, автозапуск следующей серии, стоп/старт по OK, статистика,
  вид субтитров системой, системные настройки субтитров. Кроме типа потока и системных
  субтитров, значения пока только сохраняются (`AppSettings`): читать их будет плеер.
- **О приложении**: версия, очистка кэша обложек, ID устройства.

Не перенесено, потому что в приложении нет того, чем эти пункты управляют: стартовый
экран и пункты бокового меню (главный экран один, меню нет), вид индикатора загрузки,
«Проксировать постеры», вырез на экране и свайпы (для телефонов), проверка новой версии,
лог изменений и отправка лога разработчику.

Тест скорости качает фрагменты трейлеров свежих фильмов (адрес трейлера — HLS-плейлист)
6 секунд и показывает Мбит/с; у официального приложения свой способ, цифры могут отличаться.

Проверено на телевизоре всё, кроме отвязки устройства (она разлогинивает) и
сохранения нового названия.

## Скорость интерфейса

- На телевизоре ставится **release-сборка** (`device/deploy.ps1`): отладочная в разы
  медленнее. Скрипт после установки компилирует приложение заранее (`cmd package compile`).
- На телевизоре включена служба специальных возможностей (ею лаунчер tv-home ловит кнопки
  пульта). При включённой службе Compose на каждое изменение пересчитывает семантику всех
  элементов — по профилю это была половина времени кадра. Семантика отключена у корня
  (`clearAndSetSemantics` в `MainActivity`); экранный диктор приложение не читает.
- Ответы сервера разбираются не в потоке интерфейса; карточка — свой лёгкий элемент
  вместо `Card` из tv-material.
- Метрики — в logcat под тегом `moskwin-perf` (`Perf.kt`): кадры по экранам с разбивкой
  по этапам, холодный старт, запросы, обложки. Сценарий замера — `device/perf.ps1`.
- Замер 2026-11-15, проход пультом по главному экрану и карточке: медленных кадров
  было 63–73 %, стало 2,4 %; медианный кадр 21–44 мс → 7 мс (официальное приложение на
  этом телевизоре — 6 мс); холодный старт 7,2 с → 1,0 с.
- Профиль процессора снимается с release-сборки: `simpleperf record --app pub.moskwin.tv`
  (в манифесте `profileable`).

## Окружение сборки

- Для Android SDK в сетевых настройках окружения нужен `dl.google.com`.
- Нужны пакеты SDK `platforms;android-35` и `build-tools;35.0.0`; ключ клиента — в `local.properties`
  (см. README). Сборка — `gradlew` с JDK 17–21 в `JAVA_HOME`.
- Maven Central ограничивает частоту запросов; при сбоях загрузки зависимостей помогает
  зеркало `https://maven-central.storage-download.googleapis.com/maven2/` первым в списке.
