# Что должно делать приложение

Личный клиент kino.pub для Android TV. Телевизор: Xiaomi 65" (P1 или Q1E), 4K,
около 2 ГБ памяти, слабый процессор, свой лаунчер. Стек: Kotlin, Compose for TV, Media3.

## Принятые решения

- Пишем с нуля, чужие клиенты не форкаем.
- Ключ приложения — публичный от Kodi-плагина (`client_id=xbmc`). Если отзовут,
  запасной вариант — официальное приложение.
- Список адресов API с автопереключением (сделано в `source/core/`).
- HDR / Dolby Vision и строку «Продолжить» на главном экране Google TV не делаем.
- Все записи идут в настоящий аккаунт, песочницы нет.
- Рейтинг Кинопоиска не показываем нигде. Только IMDb.

## Главный экран, сверху вниз

1. Продолжить просмотр — без детского.
2. Нелли: продолжить.
3. Новинки: фильмы — по рейтингу IMDb, без мультфильмов.
4. Новинки: сериалы — по рейтингу IMDb, без мультфильмов.
5. Рекомендации — отложено, см. ниже.

В конце ряда — карточка со стрелкой, которая открывает раздел целиком: «Новинки: фильмы»
→ каталог фильмов, «Новинки: сериалы» → каталог сериалов, ряд ребёнка → его раздел.
У «Продолжить просмотр» стрелки нет: раздела, который он продолжал бы, нет.

Избранное ребёнка на главном экране не показывается: оно открывается пунктом меню
с именем ребёнка (`KidsScreen.kt`).

«Продолжить» — одна карточка на фильм или сериал, а не на серию: обложка, название,
сезон и серия, полоска прогресса.

## Детское (Нелли)

- Детское = жанр «Мультфильм» + всё из папки закладок «Нелли».
- Детское исключается из общего «Продолжить» и из новинок.
- На карточке есть детская кнопка со значком ребёнка (добавить в папку) и «Не детское»
  (исключение для взрослых мультсериалов, хранится в приложении).
- Аниме считается взрослым контентом.
- Имя ребёнка задаётся в настройках, там же режим ребёнка выключается целиком
  (раздел «Настройки» ниже).

## Звук и субтитры по умолчанию

| | Озвучка | Субтитры |
|---|---|---|
| Нелли | русский дубляж | выключены |
| Всё остальное | оригинальная дорожка | первые русские в списке, не forced |

- Оригинал не английский — всё равно оригинал + русские субтитры.
- Русских субтитров нет — русская озвучка.
- Правило применяется при каждом запуске видео и хранится в приложении.
- Ручной выбор на конкретном сериале запоминается для этого сериала.

## Плеер и выбор дорожек

- Выбор озвучки, субтитров, качества, скорости, сервера: нажал на пункт — применилось,
  панель закрылась. Без чекбоксов и кнопки «ОК».
- При открытии панели фокус стоит на текущем выборе.
- Качество по умолчанию — 4K, если оно есть.

## Сервер

- Текущий сервер (Россия, Нидерланды и другие) виден на главном экране и в плеере.
- Переключение в два нажатия, без захода в настройки.
- Список берётся из `v1/references/server-location`, выбор пишется в настройки устройства.

## Скорость и дизайн

- Обложки кэшируются на диск, грузятся в размере под карточку.
- Главный экран рисуется из сохранённых данных, обновляется в фоне.
- В памяти только видимые ряды.
- Тёмный интерфейс в духе Netflix / Apple TV, крупные обложки.
- Анимации: только подсветка выбранной карточки и плавная прокрутка.

## Проверено на живом сервере (2026-11-15)

- Вход по коду через `https://kino.watch/api/oauth2/device` работает целиком, включая обмен
  кода на токен, с телевизора. Обновление токена вживую ещё не срабатывало (токен живёт сутки).
- Сортировка `sort=imdb_rating-` на сервере есть, но фильтр `conditions` по `imdb_votes` не
  применяется, а без него наверх выходят фильмы с десятком голосов. Поэтому новинки —
  это 150 последних из `items/fresh` (3 страницы, сервер отдаёт максимум 50), в приложении
  отсеиваются мультфильмы и всё с `imdb_votes` < 1000, остальное сортируется по рейтингу.
- У субтитров есть поле `forced` (в документации его нет); вместо `url` приходит `file`.
- У обложек есть размер `wide` (горизонтальный) — он идёт в ряды «Продолжить». Некоторые
  весят 2–3 МБ и в первый раз грузятся несколько секунд.
- «Продолжить» строится из `history` (4 страницы по 50 строк, по одной строке на серию):
  `watching/serials` отдаёт не больше 50 сериалов и без порядка, свежих в нём может не быть.
  Если последняя серия досмотрена, следующая ищется через `watching?id=`.
- `pagination.total` — число страниц, число записей — `total_items`. `history` отдаёт
  список в поле `history`, а не `items`.
- Папки «Нелли» в закладках нет; детская папка сейчас называется «мутики». Приложение
  принимает оба названия (`KIDS_FOLDER_TITLES`).
- `kino.watch/api` не обслуживает `device/<id>/settings` (404); смена сервера уходит на
  запасные адреса `api.srvkp.com` / `api.service-kp.com` — они работают с тем же токеном.
- Серверов два: Нидерланды (id 1) и Россия (id 3).
- `items/<id>`, `items/search`, `bookmarks/get-item-folders`, `bookmarks/add` и
  `bookmarks/remove-item` совпадают с документацией. `nolinks=1` ссылки всё равно
  оставляет (поле `files`), карточка сериала на 10 серий весит около 28 КБ.

Не проверено: обновление токена, время холодного запуска, поведение при 2 ГБ памяти под нагрузкой.

## Отложено

- Блок рекомендаций: источник оценок — приложение Must или IMDb. Отдельное исследование
  после главной и плеера.

## Шаги

1. Каркас и вход — готово, вход проверен на телевизоре.
2. Главный экран — пять рядов и переключатель сервера работают на телевизоре.
3. Карточка, сезоны, поиск — работает на телевизоре: карточка с описанием, сезонами и
   сериями, детская кнопка (папка создаётся как «Нелли», если детской нет) и «Не детское»
   (только у мультфильмов, хранится в приложении), поиск с экранной клавиатурой, «Назад»
   с возвратом фокуса и прокрутки. «Продолжить» в карточке выбирает ту же серию, что и
   главный экран (по отметкам `watching?id=`). Кнопка «Смотреть» и серии пока ничего не
   запускают. Не проверено: создание папки «Нелли» (детская папка уже есть) и поиск
   кириллицей с пульта (через adb вводится только латиница).
   Вне плана добавлен раздел «Настройки» по образцу официального приложения (версия 1.34,
   пункты сняты с телевизора 2026-11-15) — см. ниже.
4. Плеер — работает на телевизоре (Media3, поток HLS4). Проверено: запуск, продолжение
   с места, пауза, перемотка, смена озвучки, субтитры, список качеств, смена сервера без
   потери позиции, запоминание ручного выбора, отметки просмотра на сервере.
   Не проверено: переход к следующей серии в конце, 4K-поток, скорость, внешний плеер,
   правило «оригинал + русские субтитры» на фильме, где такие субтитры есть (на тестовом
   их не было, сработал запасной вариант). «Автофреймрейт» пока только хранится.
5. Проверка на телевизоре и доводка.

## Меню, каталог, профиль

- **Боковое меню** всегда на экране слева (`SideMenu.kt`), как у Netflix; его нет только
  в карточке и в плеере. Сверху знак «KINO PUB», ниже: Главная,
  Поиск, «Посмотрю позже», пункт с именем ребёнка (его избранное; при выключенном
  режиме ребёнка пункта нет), разделы каталога, Профиль, Настройки; текущий раздел подсвечен. «Влево» с края содержимого переводит фокус на
  пункт текущего раздела, «вправо» возвращает туда, где фокус был. Раздел из меню
  открывается вместо текущего.
- **«Назад»**: из содержимого любого раздела, включая главную, переводит фокус в меню
  на пункт этого раздела; из меню ведёт на главную; на главной с фокусом в меню
  закрывает приложение. Если фокус потерян (карточка под ним исчезла при обновлении
  данных), «назад» тоже ведёт в меню. Окна и панели внутри экрана «назад» сначала закрывает их.
  Из карточки и плеера — возврат на экран под ними.
  Шапки с кнопками на главном экране больше нет. Рядом с меню помещается пять обложек.
- **Разделы каталога в меню** и сортировка, с которой каждый открывается: Фильмы и
  Сериалы — сначала новые (`created-`); Мультфильмы — по рейтингу (`imdb_rating-`), это
  жанр 23 без раздела, то есть фильмы и сериалы вместе; дальше Концерты,
  Док. фильмы, Док. сериалы, ТВ шоу — как в списке типов сервиса. Разделов 4K и 3D
  в меню нет.
- **Сервер** выбирается в «Настройках» (раздел устройства), выбор применяется сразу.
  В плеере сервер переключается из своей панели. В меню сервера нет.
- **«Посмотрю позже»** — папка закладок с таким названием в аккаунте; приложение создаёт
  её при первом добавлении. Раздел в меню показывает её содержимое сеткой
  (`FolderScreen.kt`, тот же экран, что у избранного ребёнка).
- Кнопки одной высоты для любого содержимого и стоят на одной линии.
- **Кнопки карточки** после «Смотреть»: «Посмотрю позже» со значком закладки и детская —
  значок ребёнка без имени. Не добавлено — контур закладки и «+», добавлено — кнопка
  залита, закладка закрашена, вместо «+» галочка. Детской кнопки нет, когда режим
  ребёнка выключен. Значки нарисованы (`Icons.kt`), а не набраны символами.
- **Название приложения** в списке приложений телевизора — «KinoPub». Телевизор
  виден в списке устройств аккаунта как «KinoPub (модель)», пока имя не изменят в
  настройках.
- **Знак «KINO PUB»**: заглавные буквы шрифтом Inter Black, «KINO» белым, «PUB» на
  красной плашке `#E00206`, фон `#0F0F0F`. Значок, баннер для лаунчера и знак в боковом
  меню — картинки, их рисует `device/icons.py`; плашка строится вокруг самих букв с
  равными полями. На баннере знак занимает около двух третей ширины — как у соседних
  значков на экране телевизора. Тот же красный — цвет отметок в приложении.
- **Подгрузка каталога**: следующая страница запрашивается, когда до конца показанного
  остаётся два-три ряда. Проверка идёт при прокрутке и после каждой загрузки, порог
  считается от показанных обложек (при «Отключении аниме» их меньше загруженных). При
  сбое сети — повтор через три секунды, пока человек стоит у конца списка.
- **Каталог**: сетка обложек и пять кнопок над ней — раздел (из `types`), сортировка,
  жанр (из `genres?type=`), страна, год. Выбор применяется сразу. Сортировки: новые,
  обновлённые, рейтинг IMDb, рейтинг на сервисе, просмотры, год, название; рейтинга
  Кинопоиска нет намеренно. Страницы по 48 подгружаются при прокрутке. После возврата
  из карточки фильтры, прокрутка и фокус на месте. «Отключение аниме» действует и здесь.
- **Профиль**: аккаунт, подписка, дата регистрации, это устройство и выход из аккаунта
  на телевизоре (в два нажатия; раньше это была «отвязка» в настройках).

## Обновление приложения

- Источник — открытый репозиторий, ветка `main`: `apk/version.json` (номер версии) и
  `apk/kino-pub.apk`. Приложение читает файл версии раз за запуск (`Updater.kt`).
- Вышла версия новее — у «Настроек» в боковом меню красная точка, а в настройках первой
  строкой, с такой же точкой, стоит «Доступна версия …». По ней открывается окно со
  списком изменений (`notes` из файла версии, по строке на пункт) и кнопками «Скачать и
  установить» / «Не сейчас». APK скачивается в кэш (в строке идёт процент), затем
  открывается системное окно установки; подтверждает человек. Тихой установки нет: её
  Android разрешает только магазинам.
- Обновлений нет — та же первая строка говорит «У вас актуальная версия …», нажатие
  проверяет ещё раз. Ход проверки и загрузки и их ошибки пишутся в этой строке, а не
  рядом с заголовком экрана: там их не замечали.
- Версия проверяется при запуске и при каждом открытии настроек, а перед загрузкой —
  ещё раз: при выпуске файл прежней версии удаляется, и приложение, открытое с тех пор,
  получало бы 404.
- Окно установки запускается с `FLAG_ACTIVITY_CLEAR_TASK`: системный установщик держит
  своё окно от прошлой установки («Приложение установлено — Открыть») и без этого флага
  показывал его вместо нового запроса. Скачанный файл называется по версии.
- **Подписка**: когда до её конца меньше 7 дней или она не активна, у «Профиля» в меню
  красная точка, а в профиле первым стоит напоминание продлить её на сайте kino.watch.
  Порог — `SUBSCRIPTION_WARN_DAYS`; подписка перечитывается при возврате в приложение.
- Сборки подписаны постоянным ключом, который лежит вне репозитория. Порядок выпуска и
  про ключ — в `docs/development.md`.

## Оформление

- Стиль «жидкое стекло» (`Glass.kt`): полупрозрачные капсулы и панели со светлой кромкой
  поверх тёмного фона с цветными пятнами. Настоящего размытия нет: на Android 11 его нет
  в системе, а программное телевизор не тянет.
- Кнопки в фокусе заливаются светлым и **не увеличиваются**: увеличение размывало текст
  и наезжало на соседние кнопки. Увеличиваются только обложки.
- Рейтинг показывается без слова IMDb: под обложкой «7,9  2025», в карточке «★ 7,9».
  Это по-прежнему рейтинг IMDb; рейтинга Кинопоиска нет нигде.
- Прокрутка с опорной точкой (`PivotScroll`): карточка в фокусе всегда у левого поля,
  ряд едет под ней; по вертикали ряд в фокусе встаёт на одну высоту. Раньше ряд то
  стоял, то рывком сдвигался, когда следующая карточка была видна не целиком.

## Как устроен плеер

- Ссылки берутся из `items/media-links?mid=` перед запуском и заново при смене сервера:
  они зависят от сервера и действуют ограниченное время.
- В HLS4-плейлисте дорожки озвучки названы «08. Оригинал (ENG)»; номер совпадает с
  `audios[].index` из API. По нему дорожки плеера сопоставляются с описанием из API,
  и к ним применяется правило из `pickTracks` (`core/Models.kt`).
- Субтитры берутся отдельными файлами из API (`subtitles[].url`, SRT): только там
  известны язык и признак `forced`. Субтитры из самого плейлиста не используются.
  Файл скачивает и разбирает ядро (`core/Subtitles.kt`), а рисует сам экран плеера
  поверх видео — не через дорожку потока. Поэтому их можно сдвигать по времени и
  переключать без пересборки потока (и нет падения Media3 с подключёнными файлами).
- **Сдвиг звука и сдвиг субтитров** — два отдельных пункта панели: шаг 0,1 с, предел
  ±10 с, плюс — позже. Действуют на любую выбранную дорожку, меняются на ходу и хранятся
  по id серии или фильма (`PlaybackChoices`). Звук сдвигается через часы воспроизведения
  (`DelayedAudioFactory`): к показаниям звукового выхода прибавляется сдвиг, и видео
  уходит вперёд или назад относительно звука. Время в плашке при этом идёт по видео.
- Качество: «Авто» — адаптивно без ограничений, с высокой начальной оценкой канала,
  чтобы старт был с лучшего качества; иначе — не выше выбранной высоты.
- Пульт: OK — пауза, влево/вправо — перемотка на 15 секунд, вниз — плашка с названием
  и временем, как на паузе (второе нажатие убирает, сама гаснет через 4 секунды),
  вверх — панель настроек, «назад» — закрыть панель или выйти.
- Плашка: у фильма название; у сериала «Сериал: Серия» и тем же шрифтом, но серым,
  номер серии в виде `s01e15`. В строке состояния подписи с заглавной: «Субтитры: RUS».
- **Картинка** — пункт панели настроек плеера: целиком с полями (по умолчанию), по ширине
  экрана, по высоте экрана, заполнить экран с обрезкой краёв, растянуть. Нужен, когда
  формат фильма не совпадает с экраном. Режим примеряется сразу, как только на пункт
  встал фокус; OK оставляет его и закрывает настройки, «назад» возвращает прежний.
  Выбор запоминается для всех фильмов.
- Из списка в меню панели «назад» возвращает на тот пункт, из которого список открыли.
- **Кнопки плашки** — предыдущая серия, пауза/пуск, следующая; есть только у сериала.
  «Вниз» открывает плашку с выбранной кнопкой паузы: влево и вправо выбирают кнопку,
  OK нажимает, «вниз» или «назад» убирают плашку, сама она гаснет через 8 секунд.
  Пока кнопка выбрана, влево и вправо не перематывают. Кнопки без соседней серии
  тусклые, выбор на них не переходит. При переходе место в текущей серии запоминается.
  Значки нарисованы, а не набраны символами: с символом плашка подпрыгивала.
- Позиция отправляется `watching/marktime` каждые 30 секунд, на паузе и при выходе;
  в конце отправляется полная длительность.
- Ручной выбор озвучки и субтитров хранится по id фильма или сериала (`PlaybackChoices`).

## Настройки

Пункт «Настройки» в боковом меню. Состав повторяет официальное приложение, кроме
отвязки устройства (она в профиле).

- **Устройство** (хранится на стороне сервиса, меняется сразу): название, тест
  скорости, сервер, переключатели SSL / HEVC / HDR / 4K / смешанный плейлист.
- **Интерфейс**: «Отключение аниме» — убирает аниме из новинок.
- **Режим ребёнка**: переключатель и имя ребёнка (по умолчанию «Нелли»). Имя стоит в
  названии детского ряда и пункта меню; детской считается папка закладок с
  этим именем, а также прежние «Нелли» и «мутики». Выключен — детских рядов и кнопок
  нет, начатое детское идёт в общий ряд «Продолжить», а мультфильмы играют по взрослому
  правилу дорожек.
- **Плеер**: выбор плеера, качество, тип потока (на стороне сервиса), небольшой буфер,
  автофреймрейт, автовыбор ac3, автозапуск следующей серии, стоп/старт по OK, статистика,
  вид субтитров системой, системные настройки субтитров. Плеер читает их все, кроме
  «Автофреймрейта»: он не сделан, поэтому пункт серый и фокус не берёт. Так же
  отключается любой пункт, который не работает на устройстве (системные настройки
  субтитров — если на телевизоре их нет).
- Итог действия (скорость, ошибка) пишется рядом с заголовком экрана и не прокручивается.
- Под названием каждой настройки мелкой строкой написано, что она делает (`HINTS` в
  `SettingsScreen.kt`; для переключателей устройства, список которых приходит с
  сервиса, пояснение подбирается по названию).
- Переключатели нарисованы: дорожка с бегунком, включённый — красный.
- **О приложении**: версия, очистка кэша обложек, ID устройства.

Не перенесено, потому что в приложении нет того, чем эти пункты управляют: стартовый
экран и состав бокового меню (они постоянные), вид индикатора загрузки,
«Проксировать постеры», вырез на экране и свайпы (для телефонов), проверка новой версии,
лог изменений и отправка лога разработчику.

Тест скорости качает фрагменты трейлеров свежих фильмов (адрес трейлера — HLS-плейлист)
6 секунд и показывает Мбит/с; у официального приложения свой способ, цифры могут отличаться.

Проверено на телевизоре (2026-11-16): тест скорости, переключатель устройства, режим
ребёнка, окно имени, выбор плеера, качество, статистика, системные настройки субтитров.
Не проверено: сохранение нового названия и имени, тип потока, небольшой буфер, ac3,
автозапуск следующей серии, вид субтитров системой, отвязка устройства.

## Скорость интерфейса

- На телевизоре ставится **release-сборка** (`device/deploy.ps1`): отладочная в разы
  медленнее. Скрипт после установки компилирует приложение заранее (`cmd package compile`).
- На телевизоре включена служба специальных возможностей (ею лаунчер tv-home ловит кнопки
  пульта). При включённой службе Compose на каждое изменение пересчитывает семантику всех
  элементов — по профилю это была половина времени кадра. Семантика отключена у корня
  (`clearAndSetSemantics` в `MainActivity`); экранный диктор приложение не читает.
- Ответы сервера разбираются не в потоке интерфейса; карточка — свой лёгкий элемент
  вместо `Card` из tv-material.
- Метрики — в logcat под тегом `moskwin-perf` (`Perf.kt`): кадры по экранам с разбивкой
  по этапам, холодный старт, запросы, обложки. Сценарий замера — `device/perf.ps1`.
- Замер 2026-11-15, проход пультом по главному экрану и карточке: медленных кадров
  было 63–73 %, стало 2,4 %; медианный кадр 21–44 мс → 7 мс (официальное приложение на
  этом телевизоре — 6 мс); холодный старт 7,2 с → 1,0 с.
- Профиль процессора снимается с release-сборки: `simpleperf record --app pub.moskwin.tv`
  (в манифесте `profileable`).

## Окружение сборки

- Для Android SDK в сетевых настройках окружения нужен `dl.google.com`.
- Нужны пакеты SDK `platforms;android-35` и `build-tools;35.0.0`; ключ клиента — в `source/local.properties`
  (см. `docs/development.md`). Сборка — `source/gradlew` с JDK 17–21 в `JAVA_HOME`.
- Maven Central ограничивает частоту запросов; при сбоях загрузки зависимостей помогает
  зеркало `https://maven-central.storage-download.googleapis.com/maven2/` первым в списке.
